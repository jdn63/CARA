Temporal Risk Analysis (BSTA Framework)

The Baseline-Seasonal-Trend (BST) framework decomposes each hazard into time-horizon components for strategic preparedness. Infectious disease additionally carries an Acute component fed by CDC NSSP respiratory surveillance (outbreaks come in waves rather than smooth multi-year trends). Learn about the BSTA framework

Sparkline shows the 12-month seasonal curve for each hazard. The filled dot marks the current month ({{ current_season }}); the dashed line is the long-term baseline. Trend label reflects multi-year directional change from NOAA/FEMA/Census/climate-projection data.

Annual Planning Focus. Acute event signals (weather alerts, current AQI, recent storm counts) were retired from non-infectious domains in 2026-05 because CARA is a strategic planning tool, not an emergency-response dashboard.

How to use this analysis. Use the temporal posture to target preparedness investments:
  • Persistent baseline: long-term infrastructure and capacity building
  • Strongly seasonal: cyclical preparedness on the peak-window calendar (current season: {{ current_season }})
  • Rising trend: strategic planning and adaptation for emerging risk
  • Acute (infectious disease only): surge surveillance and response readiness when CDC NSSP activity is elevated
