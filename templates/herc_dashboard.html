About This Dashboard

All scores shown are county-balanced regional averages: jurisdiction risks are averaged within each county first, then averaged across the {{ risk_data.unique_counties_count or (risk_data.counties|length) }} counties in this {{ region_kind }} region (two-stage mean across {{ risk_data.jurisdiction_count }} jurisdictions). This prevents counties with multiple local health departments from over-weighting the regional rollup. Domain scores use the same EVR methodology and data sources as individual jurisdiction dashboards.

For granular county-level detail, select an individual jurisdiction from the home page.

What is the Kaiser Permanente HVA Tool?

The Kaiser Permanente Hazard Vulnerability Analysis (HVA) tool is a standardized approach for healthcare facilities to identify and assess potential hazards, threats, and events that could negatively affect operations. This tool is widely used in the Hospital Preparedness Program.
